Ad Unit Component Demo

Declarative ad unit lifecycle management with web components

Standard Sizes

Declare ad units with code, sizes, and optional gpid/pos attributes:

Leaderboard (728x90) - Above the fold Header Leaderboard
Medium Rectangle (300x250) - Sidebar Sidebar Ad
HTML 
<ad-unit code="header-leaderboard" sizes="728x90" gpid="/1234/homepage/header" pos="1">
</ad-unit>

<!-- pos values: 0=unknown, 1=ATF, 3=BTF, 4=header, 5=footer, 6=sidebar, 7=fullscreen -->

ORTB Format (Alternative to Sizes)

Use the format attribute for ORTB-style sizing with width/height objects:

Flexible Banner (format) Flex Banner
HTML 
<ad-unit code="flex-banner" format='[{"w":300,"h":250},{"w":320,"h":50}]' pos="3">
</ad-unit>

<!-- format takes precedence over sizes if both are provided -->
