Ad Unit Component Demo

Self-registering Prebid ad units with declarative configuration

Child Bid Elements (Recommended)

Define bidders as child <ad-bid> elements for clean, readable markup:

Leaderboard (728x90) Header Leaderboard
Medium Rectangle (300x250) Sidebar Ad
HTML 
<ad-unit code="header-leaderboard" sizes="728x90" gpid="/1234/homepage/header">
  <ad-bid bidder="appnexus" placement-id="13144370"></ad-bid>
  <ad-bid bidder="rubicon" account-id="1001" site-id="2002" zone-id="3003"></ad-bid>
  <ad-bid bidder="ix" site-id="456789"></ad-bid>
</ad-unit>

JSON Bids Attribute

For programmatic setup or simpler cases, use the bids JSON attribute:

Mobile Banner (320x50) Mobile Banner
HTML 
<ad-unit
  code="mobile-banner"
  sizes="320x50"
  bids='[{"bidder":"appnexus","params":{"placementId":789}}]'>
</ad-unit>

Hybrid (Attribute + Children)

Combine both approaches - bids from attribute and child elements are merged:

Wide Skyscraper (160x600) Skyscraper
HTML 
<ad-unit code="hybrid-ad" sizes="160x600" bids='[{"bidder":"ix","params":{"siteId":999}}]'>
  <ad-bid bidder="appnexus" placement-id="13144373"></ad-bid>
</ad-unit>
