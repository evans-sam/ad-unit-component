Banner Ad Unit Component Demo

Self-registering Prebid banner ad units with declarative configuration

Child Bid Elements

Define bidders as child <ad-bid> elements with JSON params:

Leaderboard (728x90) - Above the fold Header Leaderboard
Medium Rectangle (300x250) - Sidebar Sidebar Ad
HTML 
<ad-unit code="header-leaderboard" sizes="728x90" gpid="/1234/homepage/header" pos="1">
  <ad-bid bidder="appnexus" params='{"placementId": 13144370}'></ad-bid>
  <ad-bid bidder="pubmatic" params='{"publisherId": "156276", "adSlot": "div-1"}'></ad-bid>
  <ad-bid bidder="rubicon" params='{"accountId": 14062, "siteId": 70608, "zoneId": 498816}'></ad-bid>
</ad-unit>

<!-- pos values: 0=unknown, 1=ATF, 3=BTF, 4=header, 5=footer, 6=sidebar, 7=fullscreen -->

ORTB Format (Alternative to Sizes)

Use the format attribute for ORTB-style sizing with width/height objects:

Flexible Banner (format) Flex Banner
HTML 
<ad-unit code="flex-banner" format='[{"w":300,"h":250},{"w":320,"h":50}]' pos="3">
  <ad-bid bidder="appnexus" params='{"placementId": 13144370}'></ad-bid>
</ad-unit>

<!-- format takes precedence over sizes if both are provided -->

JSON Bids Attribute

For programmatic setup or simpler cases, use the bids JSON attribute:

Mobile Banner (320x50) - Below the fold Mobile Banner
HTML 
<ad-unit
  code="mobile-banner"
  sizes="320x50"
  pos="3"
  bids='[{"bidder":"mediafuse","params":{"placementId":13144370}},{"bidder":"33across","params":{"siteId":"examplePub123","productId":"siab","test":1}}]'>
</ad-unit>

Hybrid (Attribute + Children)

Combine both approaches - bids from attribute and child elements are merged:

Wide Skyscraper (160x600) Skyscraper
HTML 
<ad-unit code="hybrid-ad" sizes="160x600" bids='[{"bidder":"ix","params":{"siteId":"9999990"}}]'>
  <ad-bid bidder="appnexus" params='{"placementId": 13144370}'></ad-bid>
</ad-unit>
